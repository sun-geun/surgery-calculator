# 수술비 통합 계산기 v7.9.1

GitHub Pages: https://sun-geun.github.io/surgery-calculator/

## 계산기 기능
- 1~5종·1~7종·131대 수술비의 약관 기준 검색, 담보별 가입금액 비교 및 참고합계
- 상담 요약정리(A4 2페이지), PNG 이미지 저장, PDF 저장, 인쇄
- 131대 질병수술비의 지급 대분류·대상질병명·KCD·별표 개별 표기

## v7.9.1 변경
- 131대 표시명 잔여 검수 대상 **19건** 약관 원문 대조 및 수정
- N74.1* 관련 표시 **1건** 추가 정정 (총 20개 표시명)
- 제외·이중코딩·포괄범위 예외를 별도 주의문으로 분리 표시
- 기존 원본 데이터 1,106개와 검색·금액 계산 로직 유지

자세한 근거와 검수 결과는 [검수보고서.md](./검수보고서.md) 참고.

## 참고 및 한계
ADRG 독립 검색 엔진은 이번 배포에 포함하지 않습니다. 계산 결과는 교육·상담용 참고금액이며 실제 지급 여부, 면책·감액·반복수술·동일일자 수술 등은 가입 약관과 의무기록을 통해 확인해야 합니다. 131대 질병수술비 분류표의 명칭은 **대상질병명**이며 수술행위 자체의 명칭과 다릅니다.
