# 수술비 웹 계산기

GitHub Pages: https://sun-geun.github.io/surgery-calculator/

## 제공 기능
- 1~5종·1~7종·131대 질병수술비 가입금액 및 약관 항목 참고 조회
- 상단 버튼: **한 장 요약본 만들기**, **교육 예시**, **전체 초기화**
- 요약본 형식: **설계사용 / 고객 안내용**, 각각 A4 1페이지
- 요약본 이미지(PNG) 저장, PDF 저장, 인쇄
- 131대 보장그룹·약관상 대상질병명·KCD·별표 표시
- STEP 2 기존 요약정리 중복 영역 삭제

## 유지 사항
- 기존 1,106개 원본 약관 항목 및 계산·검색 로직 보존
- 별도 ADRG 검색 엔진 미탑재
- 교육·상담 참고용. 보험금 지급 여부와 금액은 계약 약관 및 의무기록 확인 필요

## 배포
`main` 브랜치의 `index.html`을 GitHub Pages에서 제공하며 별도 서버 없이 실행됩니다.
