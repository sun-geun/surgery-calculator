# 수술비 통합 계산기 (v7.8)

메리츠화재 신인 설계사 교육 및 내부 상담 참고용 통합 수술비 계산기입니다.

- 1~5종·1~7종 수술비와 131대 질병수술비 조회 및 가입금액 기준 비교 기능을 유지합니다.
- 기존 계산기 v7.8의 데이터와 산정 로직은 변경하지 않았습니다.
- **ADRG 후보 검색 엔진은 이번 배포에 포함하지 않았습니다.** 향후 별도로 검증한 후 추가합니다.
- 약관·의무기록 확인 전에는 보험금 지급 여부를 확정하는 용도로 사용하지 마세요.

## 실행 및 배포

GitHub Pages에서 저장소의 `main` 브랜치 `/ (root)`를 선택하면 루트의 `index.html`이 서비스됩니다.

예정 주소: `https://sun-geun.github.io/surgery-calculator/`

오프라인에서는 `index.html`을 직접 열어 사용할 수 있습니다.

## 파일

- `index.html` : 계산기 본체 (데이터·스타일·JavaScript 자체 내장)
- `.nojekyll` : GitHub Pages의 Jekyll 자동처리 방지
- `README.md` : 배포 안내

## 참고

공식 ADRG/Grouper 자동분류 기능은 포함되지 않습니다. 보험약관상 1~7종 ADRG 분류자료는 기존 계산기 기능을 위해 보존됩니다. 실제 보험금 지급 가능 여부와 금액은 계약 및 약관을 별도로 확인해야 합니다.
