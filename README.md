# 수술비 통합 계산기 v7.9

메리츠화재 신인 교육·상담용 수술비 참고 계산기입니다.

## v7.9 주요 기능
- 1~5종, 1~7종, 131대 질병수술비 가입금액 설정과 참고금액 비교
- STEP 2의 **상담 요약정리**: A4 2페이지 미리보기, PNG 이미지 저장, PDF 직접 저장, 인쇄
- 131대 질병수술비 참고금액에 **지급 대분류(11개 보장그룹)** · **약관상 대상질병명** · **KCD 코드** · **별표 번호** 표시
- 치핵 K64 명칭을 별표43에 따라 ‘치핵 및 항문주위 정맥 혈전증’으로 정정
- 원본 1,106개 약관 항목과 가입금액·검색 로직 유지

**ADRG 독립 검색 엔진은 이번 버전에 포함하지 않습니다.** 다만 1~7종의 종수와 ADRG 코드 관련 기존 참고조회 기능은 유지합니다.

## 실행
- GitHub Pages: https://sun-geun.github.io/surgery-calculator/
- 오프라인: `index.html`을 브라우저에서 열기
- PDF는 이미지 기반 A4 2페이지이며, 한글 표시를 보존합니다.

## 사용상 주의
보험금 지급액을 확정하지 않습니다. 감액·면책·반복·동시수술·횟수 제한, 질병 및 수술의 약관상 요건을 별도로 확인해야 합니다. 특히 131대 분류표는 ‘수술명’이 아니라 ‘대상질병명·질병코드’ 기준입니다.

131대 표시명 374개 중 PDF 텍스트 추출에서 정확히 일치하지 않는 복합명·이중코딩 항목은 별도로 추가 원문 대조가 필요하며, 이번 수정은 화면·요약 기능 중심의 검수본입니다.
